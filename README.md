## Building the Project

### Clone the repository:
```
bashgit clone https://github.com/yourusername/3-dof-proportional-nav.git
cd 3-dof-proportional-nav
```

### Create a build directory and compile:
```
bashmkdir build
cd build
cmake ..
cmake --build .
```

### Run the executable:
```
bash# On Linux/Mac:
./bin/missile_sim
```
```
# On Windows:
.\bin\Debug\missile_sim.exe
```
